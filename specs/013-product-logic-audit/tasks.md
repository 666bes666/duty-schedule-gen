# Задачи продуктового аудита

- [x] T001 [PAUD-001] Проверить все продуктовые области и сопоставить принятые решения с действующими путями выполнения.
- [x] T002 [PAUD-002] Воспроизвести значимые расхождения и сохранить отчёт с последствиями, приоритетами и ограничениями.
- [x] T003 [PAUD-005] Выполнить существующие runtime/UI проверки и сохранить реальные результаты/evidence.
- [x] T004 [PAUD-003] Провести последовательное интервью после аудита и зафиксировать принятые ответы.
- [x] T005 [PAUD-004] Уточнить требования, критерии, совместимость, plan/tasks/traceability будущей разработки.
- [x] T006 [PAUD-004] Провести speckit-analyze обновлённых контрактов и разрешить противоречия.
- [x] T007 [PAUD-005] Обновить индекс, выполнить scoped SDD/index gates и завершить evidence; доставка в dev после завершения интервью.

Порядок: T001 → T002; T003 выполняется вместе с read-only аудитом; T004 после
T002; T005/T006 зависят от принятых ответов; T007 завершает весь этап. Зелёные
тесты runtime не закрывают T004–T006. Никакая задача будущей реализации здесь
не считается выполненной.
