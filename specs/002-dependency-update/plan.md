## Риски и rollback

WeasyPrint 70 может изменить печатную компоновку; pydantic-settings меняет детали
чтения настроек; FastAPI/Pydantic могут изменить схему. Проверки API/auth/export
существуют. Solver/PDF не считать проверенными только по ранее skipped тестам.
При неисправимом регрессе откатить обновление проблемного пакета к безопасной
совместимой версии, объяснив ограничение. Откат всего изменения — git revert
коммита через тот же dev/push/PR процесс, без reset чужих файлов.
