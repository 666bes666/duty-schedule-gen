# План

Native Streamlit, существующая тема. Отдельная проверяемая функция назначает только
pending IDs атомарно; assign_roles остаётся для персональных исключений. Основной
экран: прогресс → город → выбор оставшихся → четыре профиля → продолжить. Персональные
и частичные назначения в expanders. Новый epoch пересоздаёт выбор после изменения.
Спецусловия скрываются column_order, полный DataFrame передаётся builder без потерь.
Готовность вычисляется один раз до вкладок; planning получает тот же список issues.
Bridge меняет только цвета/height по теме, не затрагивая token/hash/locks/storage.
CSS использует размеры и responsive layout без фиксированной палитры.

Проверки: unit атомарность/частичные роли, AppTest сохранение спецполей/новые labels,
UI профили/исключение настроенных/city/reload/переходы/375px/theme плюс полная регрессия.
Ruff/mypy/pytest с покрытием >=80%, UI suite, SDD scope/index, независимое ревью.
Риски: rerun сбрасывает выбор намеренно после применения; форма не сохраняет правки
до submit. Старые частичные drafts остаются в очереди. Нельзя объявить историю известной
или запускать расчёт неполной команды ради уменьшения кликов.
